# content-hit-collector

## 先判断该走哪个入口

“对标”在 AIFIOS 中不是一个动作。先按研究对象分流，避免让用户重复采集：

| 用户要回答的问题 | 使用入口 | 结果 |
|---|---|---|
| 最近哪些公开内容正在获得互动？ | `content-hit-collector` / 本期 `market-signal` | 关键词级市场样本与机制趋势 |
| 某个博主长期怎么选题、开场、组织内容？ | `/benchmark-advisor` 的“博主方法蒸馏” | 账号级方法、证据覆盖与不可迁移边界 |
| 某一条视频具体怎么推进？ | `/benchmark-advisor` 的“单条视频拆解” | 来源证据、结构、表达、制作提示与原创改写方向 |
| 某个业务是否值得模仿？ | `dbs-benchmark` | 商业模式与执行路径判断 |

`content-hit-collector` 不替代账号研究，也不根据单条爆款推断一个博主的完整人设或方法。

## 范围

只处理公众号与小红书的公开样本、用户自有账号数据或已授权材料。不得绕过登录、验证码、访问控制或平台规则。

样本写入：

```text
materials/hit-library/
├── wechat/
└── xhs/
```

## 常用命令

```bash
make hit-init PROJECT=~/ai-content-system
make hit-import PROJECT=~/ai-content-system PLATFORM=wechat FILE=/path/to/samples.csv FORMAT=csv
make hit-import PROJECT=~/ai-content-system PLATFORM=xhs FILE=/path/to/samples.json FORMAT=json
make hit-report PROJECT=~/ai-content-system PLATFORM=xhs KEYWORD="AI 咨询"
make browser-hit-fixture-check
```

## 样本字段

- 平台、标题、正文摘录、链接、发布时间
- 作者或账号标识（仅在授权范围内）
- 点赞、评论、收藏、转发等公开指标
- 来源、采集时间、可用证据与人工复核状态

字段进入报告前必须分为三类：

- **来源事实**：链接、时间、作者、内容形式、公开指标、来源直接返回的文本或主图状态。
- **结构判断**：入口机制、内容推进、互动承接、画面信息密度等由事实支持的观察。
- **待核验项**：没有正文、字幕、主图、时码或评论上下文时必须明确标注，不得用模型补造。

不要把“待人工核验的公开入口”列为可迁移机制。只有已被来源字段支持的机制才能进入蒸馏结论。

账号蒸馏必须再做一次跨作品验证：同一结构标签至少在 2 条独立作品中出现，才能标为“重复模式”并进入可迁移方法；只出现 1 次的统一标为“单样本线索”，不得据此概括博主方法。

## 对标报告

报告必须区分事实和判断，并输出：

- 高表现标题与入口模式
- 可复用的场景、冲突和评论需求
- 不应复制的夸大表达或隐私风险
- 可进入 `content-angle`、`content-breakdown` 的具体建议

账号级或单条作品级报告还应使用统一的阅读顺序：

1. **为什么进入样本**：公开表现与证据完整度。
2. **入口**：可验证的开场机制；无法确认时直接标注待核验。
3. **内容推进**：只给结构，不展示或改写第三方原文。
4. **互动与承接**：区分“已看到 CTA”与“没有返回 CTA 字段”。
5. **画面与制作**：主图可预览时只用于证据核验；没有播放和时码证据时不做镜头级判断。
6. **如何迁移**：保留机制，替换成用户自己的受众问题、事实、案例、语言和视觉。
7. **不可迁移**：账号身份、经历、标题原句、正文、封面视觉、镜头、声音和未经验证的商业结论。

## 用户体验门槛

- 默认先展示“方法蒸馏”，再进入作品样本，避免把采集列表当成最终结论。
- 同时显示“已归档总样本”和“当前时间范围样本”，不要使用同一个“内容数”造成数字冲突。
- 已归档公开主图应在列表和详情中显示；加载失败时保留来源入口和明确占位状态。
- 普通作品的结构拆解不得用固定套话冒充深度分析；应逐项显示证据、判断和缺口。
- 单条作品先归一主题、内容承诺、推进结构、论证方式、CTA 和画面信号；账号层只汇总跨作品重复项，并显示样本数和来源链接。
- 顾问追问只展示最近上下文摘要，完整历史留在项目档案，不能挤压当前操作区。
- 任何研究结论只有经用户明确“带入本期内容”后才进入当前 run。

本地 fixture 仅验证解析链路，不代表真实页面长期可用。
