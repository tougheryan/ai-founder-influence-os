# AIFIOS Skills

The installable Skill surface is defined only by `manifest.json`.

## Production Core

- `content-runtime`
- `content-intake`
- `content-hit-collector`
- `content-validate`
- `content-blueprint`
- `wechat-writer`
- `content-package`
- `content-visual`
- `xhs-card`
- `dbs-wechat-html`

## Optional Enhancements

- Visual styles: `ian-xiaohei-illustrations`, `baoyu-diagram`, `baoyu-comic`
- DBS enhancements: `dbs-action`, `dbs-benchmark`, `dbs-chatroom`,
  `dbs-content`, `dbs-decision`, `dbs-deconstruct`, `dbs-diagnosis`,
  `dbs-goal`, `dbs-learning`, `dbs-resonate`, `dbs-slowisfast`, `dbs-spread`

Existing source folders outside the manifest are migration-only compatibility
sources. They are neither installed nor shown to the production operator.

The normal delivery is a complete 1+2+3 content package. Short video output is
an execution script, shot list, subtitle emphasis, and B-roll suggestion; it
does not render or upload media.
