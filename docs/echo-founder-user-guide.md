# Echo Founder 用户使用说明书

适用对象：普通内容创作者

## 一、产品是什么

Echo Founder 是一套内容创作工作台。它把素材沉淀、选题研究、内容生产、平台排版、发布准备和复盘放在同一条工作流中，帮助你稳定产出自己的内容，而不是代替你对事实、观点和发布结果做判断。

### 使用边界

- 系统可以整理、生成、校验和归档内容，但不会替你虚构事实、来源或已发布结果。
- 系统会准备不同内容渠道的草稿信息；最终发布必须由你或发布负责人在目标渠道内完成。
- 本手册按当前界面称呼平台：公众号对应长文，小红书对应图文，视频号对应口播与拍摄执行稿。首次只做一个平台即可。
- 访问密钥、账号密码、登录态和私人素材不得写进正文、截图或交付包。
- 本手册中的界面截图只用于说明操作区域；环境配置、任务标识等非必要字段已经过匿名化处理。

## 二、开始前的准备

### 1. 完成系统设置

当前本地版打开即可进入首页和工作台，不需要产品使用密码；旧版本留下的解锁状态不影响使用。生成内容时仍需连接自己的模型服务，发布平台也保留各自的账号授权。单独配置的托管服务仍按其设备授权规则使用。

首次使用时，从侧栏“本期内容生产”进入工作台，先整理文字素材。有题目就选“按我的题目写”，需要公开参考再选“帮我找方向”；生成前进入“系统设置”连接写作服务。“连接与费用说明”可展开查看准备条件，按本篇用途配置即可：

1. 在“连接写作服务”中选择模型服务商，填写访问密钥。还没有密钥时，展开“没有密钥？准备……账号”，从对应官方入口注册或登录、创建 API Key，并核对模型权限、额度与计费方式；聊天账号的登录密码不能代替 API Key。使用自定义服务地址时，向服务提供方取得配套的密钥、地址和模型名称。已有本机密钥时无需重复填写；模型与参数需要修改时再展开“调整模型、地址与输出参数”，收起不会重置已保存的值。
2. 点击“保存设置”，再点击“测试连接”。保存不调用模型，测试会发送一次短文本请求，可能计费；成功只说明当次请求返回，不代表余额或长文质量已经验收。完成后用“回到工作台继续”返回原稿。
3. 选择“帮我找方向”时，再配置公开信息研究所需的来源与访问设置；“按我的题目写”不需要平台研究服务。研究校验未通过时，系统会暂停需要研究证据的后续环节。
4. 本篇包含公众号时，在工作台选择排版样式；设置页的“md2wechat 主题库”可查看目录。生成示例预览需要点击费用说明旁的按钮，会把内置示例发给外部排版服务，可能计费；浏览、收藏和加入对比不会自动生成预览。目录可读取不代表服务账号已可用。其他平台不需要先制作公众号排版，也不需要生图账户。
5. 如出现读取素材、生成内容或导出失败，打开桌面环境诊断，按提示重新检查运行环境和本机依赖。

平台账号授权在需要应用填入对应平台草稿时再配置，不是生成第一篇文章的前提。自己的题目、单个平台都可以完成本次内容；未选的平台不需要补做。实际使用的安装包应提供与版本对应的帮助和验收记录，源码预览中已有的能力不能自动视为旧安装包已具备。

工作台和设置中的“本期模型调用与用量”可以查看启用记录后的本期写作、模型改稿请求，包括服务、模型、时间、结果及服务返回的用量。刷新和查看不会重新生成，切换草稿只显示对应记录。没有记录不表示历史上没有费用；用量缺失保留为未知，收到响应也不等于文章已经通过检查或被采用。

工作台的“本期排版服务请求”显示本篇文章的排版和换版记录；设置中的“排版服务请求记录”还包含未绑定草稿的主题示例。每次尝试保留样式、排版版本、发起时间与结果，读取或刷新不会再次请求排版服务。取得文件不等于最终检查通过或已采用；失败、中断和首次制作回退基础排版也可能计费。记录从启用此功能后开始，不补造历史调用，金额仍未知，也不计入模型次数上限。记录损坏或读不到时会明确提示无法核对，不能据此判断没有费用。

在“本期模型调用与用量”中可设置本期累计调用次数上限，包含已经记录的成功、失败、重试和未确认请求；提高或降低上限不会清空记录。填 0 暂停新的本期写作与模型改稿请求，留空表示不限次数，已发出的请求不会被取消。保存和读取限制不调用模型。多窗口修改发生冲突时，先重新读取、核对当前限制，再决定保留输入提交或放弃输入。此限制不覆盖连接测试、独立对标、数据采集、生图或产品外调用，也不是金额上限。

绑定本期的写作请求不再由SDK或流式兼容逻辑自动重发；遇到中断先核对已有文字，再决定是否重新执行。同类操作的上次记录仅供核对，不能直接判定为失败重试。目前数据采集、生图、独立对标和连接测试未合并到这份记录，实际金额仍以服务商账单为准。

### 2. 按需补充账号与写作设置

从侧栏“素材库与创作档案”进入“创作资料库”，打开“账号与写作设置”。这里保存长期使用的账号定位和写作规则，不必为第一篇把所有栏目填满；本篇的受众、语气和禁写要求也可以直接写进素材，核对后仅用于本期。

准备保存长期设置时，填写创作者名称，再按需要补充：

- 身份定位：你希望以什么专业身份被读者认识。
- 目标受众：你希望服务、影响或吸引的人群。
- 常写主题：长期反复讨论的主题。
- 语言风格与视觉偏好：语气、节奏、排版和画面倾向。
- 表达边界：不能夸大、不能承诺、不能触碰的事实与合规限制。
- 写作规则：每篇固定要求、表达规则、不要写什么和各平台写法。

点击“保存账号设置”后才生效。“已发布内容”保存已确认发布的成稿样本；“原始素材”保存笔记、访谈、案例和参考资料。系统可以提出定位或规则更新建议，由你核对后决定是否采用，不会自动把本篇要求写成长期规则。

## 三、一次内容生产如何完成

主工作台按顺序包含 6 个必经环节和 1 个可选复盘环节。每个写有“确认”或“采用”的节点都需要人工检查后才能继续。

点击“查看草稿”，可以按草稿名、题目或已保存的素材摘要搜索，并筛选“待继续处理”“可导出”“已有发布记录”或“进度待核对”。多个关键词可用空格分开。搜索与筛选不修改草稿，不调用模型；没有结果时可清除条件。列表优先显示平台、题目、状态和下一步，素材摘要与保存时间可逐条展开。

“可导出”只表示当前文章和成品已确认且发布队列完整；只有文件、旧版本确认或下载记录都不算。“已有发布记录”可能只覆盖部分成品，需打开核对具体范围。打开另一份前会先保存当前内容，打开草稿本身不会更新输入修改时间。

### 第 1 步：添加并整理素材

1. 在“添加本期素材”的“粘贴文字”中输入笔记、访谈逐字稿、案例、观点或事实资料。
2. 如有文件，展开“文件与参考链接”，点击“选择文件”上传文档、图片、音频或表格，并确认系统已获得可用文本。
3. 如需补充创作灵感，在同一区域添加少量公开文章或视频链接。它们仅用于内部提炼，不会直接出现在最终成稿中。文件未读完或链接有误时，收起后仍会显示待处理提示。
4. 至少提供一项可读取的素材后，点击“整理素材”；输入改变后按提示“重新整理”。
5. 查看整理结果，核对事实、观点、案例、写作要求和公开边界。识别不准确时，点击“修改整理结果”，逐条修改、删除或调整分类，再保存修正。
6. 原始材料和来源保留，修正只用于本期，不会自动写入长期规则。保存修正不调用模型、不重新采集参考；方案及后续确认需要重新核对，旧稿仍可阅读。
7. 已有方案时，可点“核对现有方案”。核对修正内容、方案和已有参考是否仍适用后再确认；素材主题发生变化、原研究不再合适时，再重新研究。旧窗口的修改若与新版本冲突，填写的文字会保留，需要重新读取后核对。

建议每一轮只聚焦一个明确主题。真实、具体且有上下文的素材，比一句抽象命题更容易形成可发布的内容。

文字默认使用整行输入区域。需要更大的读写空间时，点击进度旁的“收起制作步骤”；点击“显示制作步骤”可以恢复导航。此操作不改变内容、确认状态或发布权限。

顶部“已确认几步”记录流程确认情况，不表示文章完成比例。当前任务直接显示处理中、等待连接或暂停，以及最近更新时间；“查看过程”展开后可看已完成、跳过和未开始事项。各项所需时间不同。遇到完成情况未知时，先恢复已有结果，再决定是否明确重新执行。

“不对外发布”“仅供内部使用”等限制也应保留在整理结果中。继续写作不表示同意公开发布；没有提取到限制也不代表已经获得授权。已有整理结果不会因识别规则更新而自动重写，需要时可重新整理或手动修正，再核对后续方案。超长原句可能显示限制摘录，请结合原文确认完整范围。

当本期公开边界明确写有整期“不对外发布”或“仅内部使用”时，工作台持续显示“本期仅供内部预览”；展开可看依据原句，点击“核对公开限制”返回素材页。仍可写作、排版、下载和准备本地成品，但不能由应用填入外部平台草稿。填入草稿也会把内容传给平台，确认正文不等于解除限制。模型写作仍使用你配置的服务，不表示仅在本机处理。用途变化时，应先修正公开边界，再重新核对后续方案、内容和成品。

外部草稿拦截只针对明确的整期限制；限制客户姓名、合同或某段参考，不会自动禁止整篇文章。模糊表达、漏提取的限制和具体细节是否已删除，仍须作者核对。

当前源码预览中，从成品操作区复制文字或下载 HTML、Markdown、TXT 时，如识别到整期或局部公开限制，会附上用途说明；无法核对时会标明“公开限制待核对 · 仅供内部预览”。图片等非文本文件通过下载按钮导出为 ZIP，里面保留原文件和“使用说明.txt”。说明不会加到原图上，单独转发图片会脱离附带说明。

从公众号成品的“下载排版文件／下载排版文章”保存时，同一期排版里的本地 PNG、JPG、GIF 和 WebP 配图会嵌入 HTML，保存后可断网打开，不必另带图片文件夹。原文章和图片文件不变，公开限制说明继续随下载保留。此操作不请求模型或排版服务。

如果配图缺失、引用其他期或其他版本的文件，或文章使用网络图片、外部样式、多尺寸图片等尚不支持的引用，下载会显示原因；不会交付缺少这些内容的文件，也不会自动访问网络补图。请核对素材并重新整理成品后重试。单张配图最多 16MB、全部配图最多 32MB，HTML 本身最多 8MB，最多 32 个不同图片引用；重复引用造成嵌入内容超过 48MB 时也会停止下载。此功能验证本地文件可打开，不能代替目标平台编辑器对图片与排版的验收。

用途说明可能包含限制原句中的敏感细节，仅供作者和有权查看原素材的人核对，不会自动脱敏。没有提示也不等于获得公开授权；转交文件前，应同时核对正文、图片、附带说明和接收者权限。离开应用后的转发不受此检查控制。以上为源码预览中的行为，旧安装包是否具备须以对应版本的实测记录为准。

### 第 2 步：确定题目，核对写作方案

素材核对后选择适合本期的方式：

新草稿尚未主动选择方式时，如果粘贴文字中有一个明确的作者题目，整理后会带入题目并选中“按我的题目写”。“我经营一家工作室，想写一篇文章，题目是……”这类先介绍自己再提出写作要求的表达也可带入。你可以修改题目，或改选“帮我找方向”；这一步不会自动开始研究、生成或确认。手动选择、主动清空的题目和旧草稿的方式会保留，重新整理不覆盖你的选择。引用中的题目、多个题目或没有明确题目时，不自动带入。

- **按我的题目写**：输入已有题目，点击“确认素材，按这个题目写”。系统保存题目与素材依据，再准备写作方案；不调用平台研究，也不会声称已经验证市场热度。生成方案和文章需要模型连接，可能产生所选服务的费用。
- **帮我找方向**：先研究所选平台的公开参考，再核对建议题目和写作方案。研究需要数据服务配置，可能产生额外等待和服务费用。

这两种写法在准备平台草稿时沿用同一份已确认依据。按自己的题目写，不会到交付阶段又要求补做其他平台研究；只做公众号时，也不会要求先完成小红书或视频号。仅视频号的口播执行稿可以保留在本机，无须准备图文图片。资料、题目或平台变更后，请先重新核对相关内容；旧确认不能直接用来发送新版本。

没有配置模型时，素材页在生成前显示“保存草稿并连接写作服务”。保存成功后进入设置，再返回时草稿名称、题目及步骤会保留；保存失败会留在原页。修改题目或素材后须重新核对，旧方案不能直接当作新方案确认，旧文章仍保留。

研究参考默认按“采集存档顺序”显示，不代表相关性或热度排名。没有互动记录时不能按互动排序；“已知互动合计”只合计有记录的点赞、收藏、评论和分享，不包含阅读量，缺失分项仍为未知。按互动或日期排序时，未知值放在最后。筛选只改变显示，已有参考继续保留。

两种方式都需要核对：

1. 确认写作依据：作者模式核对本期事实、观点和要求；研究模式另核对样本相关性，不把无关热点带入内容。
2. 明确本期选题的核心判断、受众价值和不应延展的边界。
3. 包含公众号时，核对本篇已选的排版样式。
4. 审阅读者、观点、结构和结尾，确认后进入写作环节。

本期写作依据、选题边界及适用的排版设置通过人工确认后，内容生产才会继续。手动核对和保存不等于模型已经生成文章。

### 第 3 步：审阅内容包

内容包按本期已选渠道分别生成原生成稿，只共享事实和表达边界，不以长文母稿派生其他渠道内容。请逐项检查：

- 长文成稿：标题、结构、事实、结论和表达边界。
- 短视频执行稿：开场钩子、口播、镜头提示、字幕重点和结尾行动句。
- 观点图文：核心观点、配文、页序和互动承接。

发布前尤其要核对数字、案例、引用、承诺性表达及可能引发误解的结论。不要只看标题就确认通过。

当前源码预览的公众号正文旁可以“复制文章”或“保存可读稿”。复制内容包含标题、摘要和正文；保存得到可独立打开的 HTML 草稿，尚未完成平台排版。两种方式都会保留当前需要附带的使用说明，不会自动确认文章或授权公开。“查看原始文件”保留完整内容包，供核对来源及制作信息。

如果提示版本已经变化，请先“重新读取文章”；自动复制不可用时，可在出现的文字框中手动复制。下载发起后，请在浏览器下载列表确认文件是否保存。最终发布仍须按后续步骤检查平台成品。

当前源码预览中，可以在公众号正文拖选文字后点击“修改选中文字”，或用每段旁的“修改这段”；原文会自动带入并聚焦到手动编辑框。预览后再决定是否采用，同一句话出现多次时只处理选中的位置。跨过隐藏说明的选区需要重新选择；原稿版本变化时也须重新选择，避免把旧选区套到新稿。

需要改稿时，点击“修改内容”，选择要替换的范围，先预览再采用。改稿区分别显示当前稿件、正在查看的修改预览和折叠的历史记录。当前稿件中可查看已采用的修改；只有仍对应当前版本时才提供撤回。

新预览会比较保存的原稿与候选稿：新增或变化的检查提示单独显示，原稿已有的整篇检查项默认折叠；阻断采用的问题不论新旧都须处理。旧记录没有比较结果时会明确说明。字数按修改后显示，篇幅以本篇已确认要求为准，不必为了默认长文篇幅补字。检查项比较不能代替事实核验，采用局部修改也不等于确认全文。

不想采用的候选可以点“暂不采用”，文字仍保存在历史中；点“恢复到待选”只恢复预览，不会覆盖正文。过期原稿、素材或关联方案会提示原因，需要基于当前版本重新修改。早前失败保留在对应记录中，不表示当前稿件失败。历史每次展开十条，可继续查看更早记录。

生成结果未通过完整检查时，可以在保留的原稿上逐项修改，点击“保存到待完成稿”。即使其他字段还有问题，本次修改也能先保存；退出重开后可继续，原始生成文字仍保留。保存待完成稿不会确认正文。处理完剩余问题后，点击“检查并另存为正式正文”，再核对全文并确认。旧窗口遇到版本冲突时，先保留自己的修改文字，再读取最新版本。

视频号的“按这篇的要求核对口播”显示实际非空白字符数和结尾原句。计数包含标点、数字，不计字幕、时间与镜头；检查使用本篇明确写下的篇幅、人称和结尾要求。没有填写的要求不会自动补成限制。这些提示帮助核对表达，事实、引用和是否适合发布仍由作者判断。


### 第 4 步：确认完整发布件

新任务固定使用 `stable` 排版，不提供 AI 生图选项，也不会要求配置生图账户或产生图片生成费用。长文渠道优先通过本机 `md2wechat` 调用外部排版 API，发送文章文字并生成完整 HTML；需要该服务的独立账号，可能产生排版费用。首次制作时，工具不可用或失败可使用内置基础排版，但回退不代表之前的外部请求没有费用。系统会保留原稿中已有的授权图片，但不会强制生成封面或正文插图。图文渠道则由本地渲染器生成 P1–P8 八张卡片。主题预览和排版请求不计入本期模型调用次数上限，实际费用需查看排版服务方记录。

每个渠道只展示一套推荐发布件。预览后按渠道整套确认即可；修改会生成一个新的排版版本，不需要比较 AI 视觉方向。

如果方案调整后仍想使用已有图文，先核对当前正文与每一页，再点击“核对并沿用这套图文”，随后正常确认排版。沿用不会重新生成图片；若正文或图片版本已经变化，系统会要求重新核对，不能用旧确认直接继续。

检查时请关注：

- 长文 HTML 是否完整、层级清楚，并保留了应当保留的授权图片。
- 图文卡片是否恰好为 P1–P8，页序、文字和比例是否正确。
- 原始图片、截图或数据图是否具备合理的使用条件和清楚的证据边界。
- 标题、页面排版和配文是否表达同一个判断。

### 第 5 步：确认内容渠道草稿

系统只为本期已选渠道分别建立草稿任务：长文渠道检查标题、摘要、完整 HTML 和原稿图片；图文渠道检查 P1–P8、正文和标签；视频渠道检查口播、镜头、字幕重点和发布文案。

此环节只准备草稿与本机交付内容，不代表已对外发布。

### 第 6 步：回填真实发布结果

在目标内容渠道完成实际发送后，回到 Echo Founder 为对应任务回填：

- 发布链接；或
- 发布截图、凭证路径；或
- 实际发布时间。

每项都必须勾选人工确认。没有真实链接、截图或凭证时，系统不会将其认定为已发布。

### 第 7 步：可选周度复盘

复盘不会阻塞本期发布，建议每周进行一次。它会汇总确认过的发布结果、表现数据和评论样本，并提出下一轮内容的优化建议。

## 四、其他功能怎么用

### 1. 内容对标研究

从侧栏“内容对标研究”进入“账号与视频分析”。这项可选功能只处理公开可见的账号和内容，用于学习结构、主题、表达角度与互动信号，不用于复制他人的原文、视觉或品牌标识，也不阻断第一篇写作。

添加对标账号时，填写公开链接、关注重点和必要备注。建议选择同一赛道但表达方式不同的账号，避免样本过于单一。

账号分析按五步进行：选择账号、收集作品、找共同做法、分析作品、用于本期内容。第一次更新后，先看“常用内容方法”，确认样本覆盖、重复做法和使用边界，再进入“作品列表与分析”。同一结构只有在至少 2 条作品中重复出现，才会进入可借鉴的常用方法；单条作品里出现一次的信号只作为待验证线索。“账号对比”用于比较各账号常用的内容方法，不应用来比较或复制人设。

作品列表同时区分“已归档样本总数”和“当前时间范围内的样本数”。已安全归档的公开主图会作为证据预览显示；它只用于核验首屏主体和信息密度，不会被复制到自己的作品。

在作品列表中选择一条内容后，可以阅读结构分析，依次检查开头、内容推进、论证方式、互动和画面制作。报告会明确标出正文、字幕、主图、可播放媒体或时码是否存在；证据不足时不会猜测镜头或完整叙事。对于公开视频，切换到“分析视频”，可进一步查看开头、结构、表达方式、拍摄剪辑提示和原创改写方向。

所有结论都应转化为自己的创作方法。点击“用于本期”或“用于本期内容”后，选中的方法或角度才会进入当前内容任务；不应直接复刻第三方标题、原文、视觉、镜头、声音、身份或经历。

### 2. 交付包与视觉工作台

内容和平台排版确认后，进入“交付包”集中审查产物。当前生产流程的交付内容包括：

- 长文内容：标题、摘要、完整 HTML、评论承接和原稿中已有的授权图片。
- 图文内容：P1–P8 页卡、标题、正文、标签和互动承接。
- 视频内容：前三秒钩子、口播、镜头、字幕重点和发布文案，不生成静态图卡。

在平台成品中点击公众号的“换排版样式”，从本期已记录的备选样式中选择，再点击“生成这版排版”。生成会将文章发给外部排版服务，可能计费。新版本生成后可分别查看已选排版和待选排版的全文；点击“使用这版排版”才替换当前选择。要换回旧版，在“成品版本”中打开旧版后再选择它，无须重新生成。

换版保留已确认的正文。所选样式未能应用时，换版失败并保留原成品，不把基础排版当成新样式；本次请求是否扣费以服务方记录为准。首次制作允许退回基础排版，界面会说明原选样式未应用。旧成品缺少实际样式记录时会提示核对，不推断它已使用某个主题。

小红书图文仍可通过“修改这套”或“修改这张”提出修改要求，再比较和选择。新任务不会调用 AI 图片生成服务。

交付前请依次运行内容质量验收和交付审查。只有审查结果允许交付时，再生成交付包。下载前检查隐私扫描，确保访问密钥、登录态、浏览器资料、会话文件等敏感信息不在交付内容中。

### 3. 平台草稿与发布结果

“平台草稿与发布结果”适合在产物路径生成后集中管理草稿队列。

1. 填写本期内容包和发布成稿路径；如需要，可补充排版清单与任务编号。
2. 点击“生成草稿队列”。
3. 加载后逐项查看内容类型、状态和本机交付信息。
4. “继续队列”只会处理可重试或待准备任务，不代表系统会对外发布。
5. 草稿就绪后，在目标渠道检查格式、图片顺序、标签和发布时间；实际发送由人工完成。
6. 发布完成后，填写链接或凭证、实际时间，并勾选人工确认。

当状态显示“可重试”“待人工处理”或“完成状态未知”时，请先在目标渠道核实，不要假设发布成功。

### 4. 发布数据复盘

从侧栏“发布数据复盘”进入“本周发布复盘”，点击“汇总本周发布”，再补充真实表现数据，例如阅读、播放、点赞、分享、收藏、评论、新增关注、主页访问或线索。

可以录入有代表性的评论样本，但不要记录读者的私人信息或不应长期保存的内容。报告生成后，人工检查建议是否基于足够样本、是否符合创作定位；确认后才写入长期学习。

## 五、日常使用建议

### 每周节奏

1. 周初：补充素材，更新本期主题与研究方向。
2. 创作日：按 1 至 5 步完成内容、平台排版与草稿确认。
3. 发布日：人工完成发送，并回填链接或凭证。
4. 周末：汇总表现数据，确认下周值得保留的经验。

### 常见问题

**“整理素材”不可点击**

至少添加文字、文件或灵感链接；若上传文件无法读取，请补充可复制文本、识别结果或逐字稿。

**无法继续题目或写作方案**

先确认素材已整理、文件可读取，并核对本次平台选择。按页面提示分别处理：

- **按我的题目写**：填写“这期想写什么”，确认素材与题目；生成方案需要可用的模型连接，不需要配置 TikOmni。缺模型时去设置保存并测试，再用“回到工作台继续”返回原稿。素材或题目变更后，先重新核对依据。
- **帮我找方向**：核对研究服务配置及本次已选平台的研究结果。某个平台失败时，按提示重试或调整所选平台；不要求补做未选平台，也不把历史参考当作本次研究。
- **没有可用排版样式**：包含公众号时，检查设置页的主题库是否成功读取，再返回工作台选择可用样式；不要通过重复调用模型处理样式读取问题。

**排版发布件无法确认或交付包无法生成**

确认长文 HTML 或图文 P1–P8 已真实生成，并按渠道确认完整 revision，再运行质量验收和交付审查。审查出现阻断项时，应先补齐产物或修复质量问题。

**成品下载失败**

当前源码预览会在下载按钮旁显示原因，并保留工作台页面。按提示核对文件是否仍存在或处理大小限制后，再点击原下载按钮重试；不必因此重新生成文章。单个文件超过 256 MB 时需要先拆分。

**发布状态显示未知**

以目标内容渠道中的实际页面为准。核对公开链接、草稿状态或发布截图后，再回到系统回填。

## 六、本篇交付与发布检查清单

只检查本篇实际选择的平台和功能，不要求完成三个平台或填写整份长期档案。

- [ ] 已连接本篇使用的写作服务，并确认费用归属；连接测试成功不等于余额或内容质量通过验收。
- [ ] 本期素材真实、可读，写作要求和表达边界已经核对。
- [ ] 已核对自己的题目及素材依据；选择研究路径时，另核对所选平台的参考来源和相关性。
- [ ] 已审阅本次所选平台的成稿，核对事实和表达；未选平台无需生成。
- [ ] 如包含公众号，已检查完整 HTML；如包含小红书，已检查 P1–P8 的页序、文字和比例；只选视频号时，核对口播与拍摄执行稿即可。
- [ ] 已检查本次成品与草稿信息，明确准备草稿不等于已公开发布。

实际发布后，再登记真实链接或凭证与人工确认。发布数据和周复盘可后补；没有发布就保留未发布，缺失数据不填零。

## 七、操作区图示索引

既有配套图用于辨认操作区域；旧图中的名称不能证明当前安装版本具备相同能力。当前入口对应如下，交付方仍需以实际交付版本核对随包图示：

1. 系统设置：连接写作服务、桌面环境诊断和 md2wechat 主题库。
2. 素材库与创作档案：打开后为“创作资料库”，包含“账号与写作设置”“已发布内容”和“原始素材”。
3. 本期内容生产：阶段导航、素材输入与确认入口。
4. 内容对标研究：打开后为“账号与视频分析”，可查看常用内容方法、作品列表与分析、账号对比或分析视频。
5. 交付包与视觉工作台：审查、排版预览与整套确认入口。
6. 平台草稿队列：草稿准备与人工发布回填区域。
7. 发布数据复盘：打开后为“本周发布复盘”，可汇总本周发布并核对指标状态。
