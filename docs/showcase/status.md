## 为什么暂未放出安装包

当前包属于内部快照，尚未完成 Developer ID 签名、公证、干净源码冻结与公开分发验收。已有本机启动、恢复、备份和持续运行检查，不能代替陌生使用者在另一台 Mac 上完成首篇的验证。

随包第三方组件还需要逐项完成公开分发授权复核，包括 xhs-card 的 AGPL 许可证与 TikOmni connector 的授权范围。md2wechat 没有打入内部包，它的使用条件需单独遵循。

这些是当前交付条件。付费意愿和客户复用则是另一项商业验证，不应与软件下载量混为一谈。
