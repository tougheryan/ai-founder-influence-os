# Echo Founder 内部测试版安装说明

当前内部测试产物为 `Echo-Founder-0.2.0-beta.2-mac-arm64.dmg`，仅支持 macOS 13+ Apple 芯片 Mac。

请使用以下正式说明完成交付：

- [安装与首次启动](echo-founder-installation.md)
- [API、研究与平台桥配置](echo-founder-api-platform-setup.md)
- [项目备份、恢复与升级](echo-founder-backup-upgrade.md)
- [商业交付矩阵](../quality/commercial-readiness-matrix.md)

本版没有 Apple Developer ID 签名与公证，只能作为内部测试版；首次可能需要在 Finder 中按住 `Control` 点击 `Echo Founder.app` 后选择“打开”。不要关闭 Gatekeeper，也不要把自动化门禁结果当作真实账号验收记录。

历史文档中的 AIFI-OS/AIFIOS 仅为内部工程与兼容标识，外部产品名统一为 Echo Founder。
